# 6列サンキー図リアーキテクチャ設計

## 概要

行政事業レビューのデータを6列のサンキー図で可視化し、予算から支出までの流れをより詳細に表現する。従来の2列構成から6列構成に拡張し、メイン画面とドリルダウン画面で異なる構造を採用する。

## 目的

- **詳細な資金フロー可視化**: 府省庁 → 事業 → 予算総計 → 支出総計 → 府省庁 → 支出先の6列構造
- **柔軟なTopN設定**: 列ごとに異なるTopN設定とソート順
- **差額の可視化**: 予算と支出の差額を明示的にノード表示
- **ドリルダウン対応**: 府省庁・事業・支出先から詳細画面への遷移

## データ構造

### 画面種別

1. **メイン画面** (6列構造)
   - 列1: 各省庁の事業予算TopN
   - 列2: 各省庁ごとの予算合計
   - 列3: 予算の総計
   - 列4: 支出の総計
   - 列5: 各省庁ごとの支出の総計
   - 列6: 各省庁の支出TopN

2. **省庁ブレイクダウン** (4列構造)
   - 列1: 事業予算TopN
   - 列2: 予算合計
   - 列3: 支出の総計
   - 列4: 支出TopN

3. **事業ブレイクダウン** (3列構造)
   - 列1: 予算合計
   - 列2: 支出の総計
   - 列3: 支出TopN

4. **支出ブレイクダウン** (3列構造)
   - 列1: 支出合計
   - 列2: 支出の総計 (同じ値)
   - 列3: 事業TopN

## 差額ノードの実装

### 差額計算ロジック

```typescript
interface DifferenceNode {
  type: 'difference';
  budgetTotal: number;
  executionTotal: number;
  difference: number; // |budgetTotal - executionTotal|
  direction: 'budget-excess' | 'execution-excess'; // どちらが多いか
}

// 差額ノード追加ロジック
function addDifferenceNode(budgetTotal: number, executionTotal: number): DifferenceNode | null {
  const difference = Math.abs(budgetTotal - executionTotal);

  // 差額が総額の0.1%未満なら無視
  const threshold = Math.max(budgetTotal, executionTotal) * 0.001;
  if (difference < threshold) {
    return null;
  }

  return {
    type: 'difference',
    budgetTotal,
    executionTotal,
    difference,
    direction: budgetTotal > executionTotal ? 'budget-excess' : 'execution-excess',
  };
}
```

### 差額ノードの配置

- **予算 > 支出**: 列3 (予算の総計) に差額ノードを追加
- **支出 > 予算**: 列4 (支出の総計) に差額ノードを追加
- **表示**: 「差額: XX億円」ラベル、グレー色

## TopNとソート機能

### TopN表示ロジック

```typescript
interface TopNResult<T> {
  topItems: T[];        // TopN件
  othersItems: T[];     // TopN以外
  othersTotal: number;  // TopN以外の合計額
}

function selectTopN<T>(
  items: T[],
  topN: number,
  getValue: (item: T) => number,
  sortOrder: 'asc' | 'desc' = 'desc'
): TopNResult<T> {
  const sorted = [...items].sort((a, b) => {
    const diff = getValue(b) - getValue(a);
    return sortOrder === 'desc' ? diff : -diff;
  });

  const topItems = sorted.slice(0, topN);
  const othersItems = sorted.slice(topN);
  const othersTotal = othersItems.reduce((sum, item) => sum + getValue(item), 0);

  return { topItems, othersItems, othersTotal };
}
```

### ソート設定

- **列ごとの独立したソート**: 各列で異なるソート順を設定可能
- **デフォルト**: すべて降順 (金額が大きい順)
- **TopN以外の配置**: `othersAtBottom: true` で最下部固定

## 互換性とマイグレーション

### 既存データとの互換性

- **段階的移行**: 既存の2列データと新6列データを並行運用
- **フォールバック**: 6列データがない場合は従来の2列表示
- **データバージョニング**: `version: 2` をメタデータに追加

### ユーザー設定の移行

```typescript
// 既存設定を新設定に変換
function migrateConfig(oldConfig: SankeyConfig): SankeyConfigV2 {
  return {
    ...oldConfig,
    topN: {
      mainTopProjects: 3,
      mainTopExpenditures: 3,
      ministryTopProjects: oldConfig.topProjectsCount || 10,
      ministryTopExpenditures: 10,
      projectTopExpenditures: 20,
      expenditureTopProjects: 30,
    },
  };
}
```

## パフォーマンス考慮

### データサイズ削減

- **事前計算**: TopNを前処理時に計算してJSONに含める
- **遅延ロード**: ブレイクダウンデータは必要時にのみロード
- **圧縮**: gzip圧縮でファイルサイズ削減

### レンダリング最適化

- **メモ化**: useMemo でフィルタリング結果をキャッシュ
- **仮想スクロール**: モーダルの大量データ表示時
- **debounce**: 設定変更時の再レンダリング制御
